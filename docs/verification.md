# 관리자 웹 검증

사용자 본인의 실제 학교 로그인·최초 등록·인증 앱 TOTP 확인 후 관리 화면 진입을 확인했습니다. 서버에서도 활성 관리자 1명, TOTP 확인 기록과 유효한 MFA 세션 1명을 확인했습니다. 아래 합성 UI 검사는 실회원 변경을 대신하지 않으며, 실제 Minecraft 연결 후 권한 회수 시험은 별도로 진행합니다.

검증일: 2026-09-30.

## 관리 기능 구현 후 검증

독립 TypeScript 검사와 Vite production build를 통과했습니다. React 구성의 의존성·요청 정리·민감한 상태 수명을 검토했으며 `git diff --check`도 통과했습니다.

브라우저 기능 검증은 운영 API 계약과 같은 응답을 제공하는 **루프백 합성 API**에서 수행했습니다. 모든 이름·회원·키·코드는 가상 데이터입니다. 실제 학교 로그인, 실회원 변경, 실제 명부 반영을 수행했다는 의미가 아닙니다.

- 최초 등록 코드 입력 → 인증 앱 수동 등록 키 표시 → 6자리 MFA → 관리 화면 진입
- MFA 후 CSRF 값 회전, 새 CSRF로 관리 변경 요청 성공
- MFA 성공 후 등록 키의 DOM 제거, localStorage·sessionStorage 저장 0건
- 잘못된 MFA 코드 안내와 입력값 제거
- 실제 응답에 따른 통계와 명부·서버 현황 표시
- 회원 커서 페이지네이션, 접근 정지와 명부 범위 내 서버 제한 저장
- 명부가 허용하지 않은 서버는 선택할 수 없음
- Minecraft 연결 해제는 확인 체크 전 비활성화, 승인 후 목록 갱신
- 위험 명부 미리보기는 승인 전 반영 비활성화, 승인 후 검토한 digest 전송
- `409 approval_mismatch` 응답 시 승인·미리보기 제거와 재확인 안내
- 운영 기록 조회와 변경 내용 펼치기
- 서버의 MFA 만료 응답 후 관리 데이터·메뉴 제거와 추가 인증 화면 복귀
- 로그아웃 후 학교 로그인 화면 표시
- 학교 로그인 오류 콜백 안내와 주소의 `auth_error` 제거
- 브라우저 런타임 오류 없음

## 화면 검증

- ALMS v4 A 레이아웃과 사용자 지정 Pretendard 유지
- 데스크톱 1440×900의 등록·운영 현황·회원·명부 화면 확인
- 모바일 390×844의 운영 기록·MFA·명부 화면 확인, 가로 넘침 없음
- 사이드바 216px, 상단 바 64px, 주 버튼 `#1B64DA`
- Pretendard Variable 폰트의 실제 `loaded` 상태 확인

## 이전 배포 검증 이력

관리 기능 추가 전 실제 개발 API에 배포한 UI에서 접근 거부 안내, 포털 로그인과 관리자 세션 분리, HTML의 CSP·Referrer-Policy·X-Frame-Options·nosniff·no-store를 확인했습니다. 당시 폰트 요청 HTTP 200과 2,057,688바이트도 확인했습니다. 이 이력은 이번 관리자 기능의 운영 배포 검증을 대신하지 않습니다.

## 남은 실제 연동 검증

운영 설정과 최초 운영자 등록 이후 학교 로그인 → 실제 인증 앱 MFA → 실제 회원 조회, 실제 Google Sheets 변경 미리보기·반영을 확인해야 합니다. 게임 서버의 접속 중 정책 회수와 계정 연결 해제 반영도 별도 검증 대상입니다. 이 웹 저장소의 브라우저 합성 API 검증과 API 저장소의 DB·인가 검증은 서로 다른 범위입니다.

## 운영 HTTPS 익명 브라우저 확인

2026-09-30, 배포된 관리자 HTTPS 주소를 사용자의 로그인 세션과 분리된 브라우저에서 확인했습니다.

- 1440×900·390×844에서 학교 로그인 안내 정상 표시, 빈 화면·오버레이·가로 넘침·JavaScript 오류 없음
- 실제 세션 API와 관리자 세션 API HTTP 200, 익명·MFA 미인증 상태 확인
- 실제 학교 로그인 시작 API HTTP 200, 고정 SmartID HTTPS origin·경로와 관리자 호스트의 콜백 확인
- 이동 주소는 사용자명·비밀번호·fragment를 거부하며, 소스의 주소 검증 7개 조건 확인 통과
- Pretendard `loaded`, 폰트 HTTP 200·2,057,688바이트, 사이드바 216px·상단 바 64px·주 버튼 `#1B64DA`
- localStorage·sessionStorage 저장 0건

학교 비밀번호·TOTP를 입력하지 않았고 실제 관리자 권한 등록이나 실회원 변경은 수행하지 않았습니다. 로그인 시작 응답은 호스트·경로 형태만 확인했으며 state·토큰 원문은 출력하거나 저장하지 않았습니다.
