2026-09-30, 새 UI를 실제 개발 API와 연결한 배포에서 확인했습니다.

- 데스크톱 1440×900, 모바일 390×844 화면 직접 확인 및 가로 넘침 없음
- 사이드바 216px, 상단 바 64px, 개발 표시 28px
- 주 버튼 `#1B64DA`, 중립 선택 메뉴와 v4 A 카드·간격 적용

- 원본 SVG 브랜드 22×22, 메뉴 18×18 크기 유지
- 실제 관리자 API의 접근 거부 응답에 따라 ‘운영자 인증이 필요합니다’ 표시
